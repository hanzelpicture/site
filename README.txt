HANZEL.PICTURE — PORTOFOLIO WEBSITE
====================================

Isi:
- index.html : struktur seluruh website
- style.css  : desain responsif, warna hitam/emas, tipografi, animasi
- script.js  : menu mobile, animasi saat scroll, pilihan layanan, formulir WhatsApp

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser, atau unggah semua file ke hosting statis.
3. Koneksi internet diperlukan untuk Google Fonts dan gambar contoh dari Unsplash.

PENTING:
- Gambar yang saat ini digunakan adalah gambar contoh dari Unsplash, bukan foto yang dikirim oleh pemilik.
- Ganti URL background-image di style.css dengan foto karya Hanzel.Picture untuk memakai foto asli.
- Form konsultasi membuka WhatsApp ke nomor 088294849594 (format internasional 6288294849594).
- Tidak ada harga atau estimasi biaya yang dipublikasikan. Form mengumpulkan detail agar estimasi dapat dibahas langsung.
- Tim ditampilkan tanpa foto sesuai permintaan.
- Website statis ini tidak menyimpan data formulir; pesan disusun di browser dan diteruskan ke WhatsApp setelah pengguna menekan tombol.

Kustomisasi:
- Ubah teks, layanan, dan cerita di index.html.
- Ubah warna utama pada variabel CSS di bagian :root dalam style.css.
